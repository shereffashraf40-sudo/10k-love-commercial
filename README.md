# 10k-love-commercial
منصة «10 آلاف قصة حب» مساحة رقمية لمشاركة قصص الحب والمشاعر والذكريات، من خلال 10,000 مربع مخصص للقصص. تتيح المنصة نشر القصص باستخدام أكواد تفعيل، مع نظام دفع يدوي بقيمة 200 جنيه مصري للقصة، والتواصل عبر واتساب لتأكيد الدفع واستلام الكود. هدفنا جمع آلاف الحكايات الإنسانية في مكان واحد.
